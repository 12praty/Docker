==>What does Dockerization mean?
   Dockerization means packaging your application and its runtime environment into a Docker image so that it can run consistently on different machines.
==>Imagine you've built a Java web application. To run it, you need several things:
- Java runtime
- A web server such as Apache Tomcat
- Your compiled application (.war file)
- The correct configuration
Without Docker, you may need to install and configure these separately on every server.
==>Why do we Dockerize applications?
1. Portability: Run the same image on your laptop, EC2, or another server with Docker.
2. Consistency: Reduce differences between development and production environments.
3. Easy deployment: Build an image once and distribute it through Docker Hub.
4. Isolation: The application runs in its own container environment.
5. Scalability: Run additional containers when needed.

==>ou're almost correct! Just one important correction: you don't need a separate Docker server to host your application. Let's understand the whole process.
How it actually works
1. Java project
Your source code

2. Docker image
Your application + Tomcat + required runtime

3. Docker Hub (optional)
Stores your image so you can distribute it

4. AWS EC2
Runs Docker, which starts your container

5. Users access your website
Using your EC2 public IP and exposed port


What does each component do?
- Docker image: Packages the app with its required runtime environment, helping it run consistently across machines.
- Docker Hub: A registry that stores and distributes Docker images. You don't have to use Docker Hub; other registries or direct image transfers are possible.
- EC2: The cloud machine where your application runs.
- Docker Engine: Runs your image as a container on EC2.
- Tomcat: Runs your Java web application and handles web requests.
- Public IP + security group: Lets users reach your application over the network when configured correctly.

==> install maven

$ sudo yum install maven -y

$ mvn archetype:generate -DgroupId=com.telusko -DartifactId=my-web-app -DarchetypeArtifactId=maven-archetype-webapp -DinteractiveMode=false

$ cd my-web-app

$ vi pom.xml

<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/maven-v4_0_0.xsd">
  
  <modelVersion>4.0.0</modelVersion>

  <groupId>com.telusko</groupId>
  <artifactId>my-web-app</artifactId>
  <packaging>war</packaging>
  <version>1.0-SNAPSHOT</version>
  <name>my-web-app Maven Webapp</name>
  <url>http://maven.apache.org</url>

  <properties>
    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  </properties>

  <dependencies>
    <dependency>
      <groupId>junit</groupId>
      <artifactId>junit</artifactId>
      <version>4.13.2</version>

    </dependency>
  </dependencies>

    <finalName>my-web-app</finalName>

        <groupId>org.apache.maven.plugins</groupId>

  </build>
